# Development fixture image assets

These images are embedded only in the disposable `teamtaler-testdata` binary.
The fixture normalizes them through the production media pipeline before
attaching them to products or fictional local test accounts.

The water and apple-spritzer images reuse the unbranded OpenAI-generated demo
assets created on 2026-08-04. The remaining product and profile images were
generated with the built-in OpenAI image generation tool on 2026-08-13.

All depicted people are fictional. The assets contain no third-party logos,
trademarks, or intended resemblance to real individuals.
