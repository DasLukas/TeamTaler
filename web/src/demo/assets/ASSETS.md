# Demo product assets

The product images in this directory were generated with the built-in OpenAI image generation tool for the TeamTaler demo catalog on 2026-08-04.

- `water.webp`: unbranded reusable water bottle at a sports field.
- `soda.webp`: unbranded orange-cola soda bottle in a clubhouse.
- `beer.webp`: unbranded lager glass on a sports-club terrace.

These images contain no third-party logos or trademarks and are used only as replaceable seed data. They are imported only by the development demo module, which is removed from production builds. Uploaded product images remain owned and managed by each TeamTaler installation.
