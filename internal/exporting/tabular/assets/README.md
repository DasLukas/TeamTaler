# Embedded Noto Sans assets

The PDF renderer embeds the regular and semibold Noto Sans TrueType fonts so
exports remain Unicode-capable and independent of fonts installed on the host.

Both files were obtained from the official `notofonts/noto-fonts` repository at
commit `c971829a87e7920f960e7277c3dafd9bedd3c601`:

- `NotoSans-Regular.ttf`: SHA-256 `b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`
- `NotoSans-SemiBold.ttf`: SHA-256 `87a8b90ece1e89746b544e4e086f85a3710e41485a8078f9be874837dfad45d5`

The fonts are redistributed under the SIL Open Font License 1.1. The complete
license is included in `LICENSE-NOTO-SANS.txt`.
